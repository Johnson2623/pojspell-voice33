教育部詞條音檔整合說明（點擊才播放）

目前此 ZIP 包含更新後的 index.html 和使用說明，未包含教育部音檔本身。

使用方式 A：
1. 從教育部臺灣台語常用詞辭典下載「詞條音檔 mp3」ZIP，解壓縮。
2. 用 Chrome 開啟 index.html，點「載入音檔」選取多個 MP3（或「載入音檔資料夾」選取整個解壓後資料夾）。
3. 於「互動閃卡」「詞庫總覽」「辨識測驗」點擊「▶ 聆聽」，才會播放。
4. 每次重新整理或重新開啟 HTML，須重新選檔，因瀏覽器不允許網頁永久讀取本地檔案。

使用方式 B（固定資料夾）：
在 index.html 同一層建立 audio 資料夾，放入官方原始檔名，例如 1658(1).mp3。
程式會用「詞目id」與原始 A1 詞目表「羅馬字音檔檔名」對應。
若由本機 file:// 開啟相對路徑音檔受到瀏覽器安全設定限制，請用 HTTP(S) 網頁伺服器開啟。

尚未經由使用者提供官方音檔，故此版本並非可立即離線發聲的完整版。
所有音檔應依官方授權規定使用。
